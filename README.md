# Git Reference

A single-page, searchable learning reference for Git — from the mental model and everyday commands to reflog recovery, interactive rebase, bisect, worktrees, hooks, plus fixes for 25+ common Git errors and tools for debugging Git itself.

**Live site:** https://choicespecs.github.io/git-reference/

Features: instant search (press `/`), copy buttons on every snippet, light/dark theme, mobile-friendly layout. No build step — just `index.html`.
